## Descripción
Este repositorio contiene el notebook del TFG sobre predicción 
de precios relativos de inmuebles residenciales en Madrid mediante 
modelos de Machine Learning.

## Cómo ejecutar el notebook
1. Abre el notebook en Google Colab
2. Descarga el dataset desde Kaggle:  
   https://www.kaggle.com/datasets/mirbektoktogaraev/madrid-real-estate-market
3. En el panel izquierdo de Colab, sube el archivo `houses_Madrid.csv`
4. Ejecuta todas las celdas: Entorno de ejecución → Ejecutar todo

## Contenido
- Preprocesado y limpieza de datos
- Análisis exploratorio (EDA)
- Definición de Target A y Target B
- Entrenamiento de Ridge, Lasso, Random Forest, XGBoost y MLP
- Evaluación con K-Fold k=10
- Análisis de residuos e importancia de features
